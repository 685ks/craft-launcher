Link icons
==========

`github.svg` is from [Simple Icons](https://simpleicons.org/) 16.34.0
(`https://cdn.jsdelivr.net/npm/simple-icons@16.34.0/icons/github.svg`), released under
[CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md). The only change is
`fill="#ffffff"` on the root element, so the app can tint it to the theme.

`globe.svg` is the `globe` icon from [Lucide](https://lucide.dev) (lucide-static 0.468.0,
`https://cdn.jsdelivr.net/npm/lucide-static@0.468.0/icons/globe.svg`), licensed
[ISC](https://github.com/lucide-icons/lucide/blob/main/LICENSE). The only change is
`stroke="#ffffff"` instead of `currentColor`, so the app can tint it to the theme. It stands for
the project's home page.

The GitHub logo is a trademark of GitHub, Inc. It is used only to link to this project's own
GitHub pages.

Arthavan Projects portable mode

While this file sits next to arthavan-projects.exe, Arthavan Projects keeps its settings, its
download cache and its record of installed apps in the ArthavanProjectsData folder beside it, and
writes nothing to %APPDATA%. Copy the whole folder to move Arthavan Projects with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\Arthavan Projects) instead.
If ArthavanProjectsData can't be written (for example on a read-only drive), Arthavan Projects says
so and uses %APPDATA%\Arthavan Projects instead.
